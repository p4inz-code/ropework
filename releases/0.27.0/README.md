Ropework 0.27.0, beta (Windows 11, x64).

- Installer: `Ropework-Setup-0.27.0.exe` (for your user only, no administrator rights)
- Portable: `ropework-0.27.0-win-x64-portable.zip` (unzip anywhere, run `Ropework.exe`)
- Check the download against `SHA256SUMS.txt` (`Get-FileHash <file> -Algorithm SHA256`).

The beta is free and needs no key. The files are not code-signed yet, so Windows may say "Windows protected your PC": choose More info, then Run anyway, after checking the checksum. You also need the free `p4` command-line client from Perforce.

What is in this release: https://p4inz-code.github.io/ropework/releases/
Questions and bugs: open an issue in this repository.
