Check your download

In PowerShell, in the folder you saved it to:

Get-FileHash "Ropework Setup 0.27.0.exe" -Algorithm SHA256

The result must match the SHA-256 shown above.

After installing

The app works without a key during the beta. Questions and bugs go to the issue tracker.

No Ubuntu build in this release. An Ubuntu 24.04 package (AppImage and .deb) is planned for a later release. It will appear here with its checksum.
