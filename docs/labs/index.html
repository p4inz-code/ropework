More from P4inz

Other software by P4inz Interactive Labs, with links.

Ropework is one of several tools made by P4inz Interactive Labs, an independent studio run by Atharva Patil. The others are listed here. A machine-readable version is at /ecosystem.json.

  • Kanvaz. A free, open-source, offline infinite-canvas reference board for VFX and 3D artists
  • Kanvaz Mini. A small always-on-top reference window, the quick version of Kanvaz
  • OutlineDesk. An offline production planner for animation, VFX and game studios
  • Nexus Desktop. An encrypted desktop vault for Windows that works offline and has no telemetry
  • Crossport. A free, offline Windows file-transfer utility that shows its plan before anything moves
  • MINK. A programming language focused on clarity, performance and safety
  • Pursue OS. A privacy-first workspace for OSINT and digital investigations
  • 3D Ref Skills. An AI skill pack for 3D pre-production reference work, free and MIT licensed
  • Reference Engineering. A reference engineering library from app development to VFX
  • repo-map. Generates architecture overviews of a code repository as Markdown or JSON
  • Project Ascent. An offline 2D precision platformer
  • Portfolio. The personal portfolio of Atharva Patil

The code and releases of all public projects are on GitHub.
