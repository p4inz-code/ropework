Support

How to ask for help, what to include, and answers to the questions that come up most.

Support during the beta is best effort. No reply time is promised. A support email address will be added later; for now the issue tracker is the place to ask.

Ask or report a problem

Open an issue and pick the template that fits: something broke, something was confusing, or an idea. Please do not post passwords, server addresses or private file names.

What to include

The Ropework version (Help, About), the version of your Perforce server, what you did and what you expected. In the app, Help, Send feedback builds a short text with the version and the commands that ran recently. It has no file names, server addresses or passwords, and you can read it before you copy it.

Questions that come up

Windows says it protected my PC.

The installers are not code-signed yet. Check the checksum on the download page, then choose More info and Run anyway.

Ropework cannot find p4.

Ropework uses the free p4 command-line client from Perforce and does not bundle it. The first start tells you where it looked and lets you type the path.

Do I need a licence key?

No. The beta is free and never blocks anything. A key is only recorded on your computer.

I reverted something by mistake.

Ropework saves a copy before a revert, a delete, a resolve or a forced get latest, and keeps it for 14 days. Use File, Safety copies, or the Undo in the notification.

The server is not reachable.

A band at the top says so. You can still read the folders you opened before, from the saved copy, and Ropework retries by itself.

Security problems

Please do not open a public issue. Use private reporting on GitHub instead. See also Privacy and security.

Before you write

Look at the known issues. Yours may already be listed with a way around it.

Your files and server details never leave your network. Ropework contacts our licence service only to confirm your licence.
