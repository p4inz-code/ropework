# Ropework

A calm desktop client for Perforce Helix Core, by P4inz Interactive Labs. It shows what will happen before it happens, undoes what it did, and keeps your files and server details on your network.

- Website: https://p4inz-code.github.io/ropework/
- Status: private beta (Windows 11 now, Ubuntu 24.04 next). Download and request a beta key on the website.
- Ropework is an independent product and is not affiliated with Perforce Software.

This repository holds the public website (`docs/`), downloads and release notes. The application source is private.
