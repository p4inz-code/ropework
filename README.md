# Ropework

A calm desktop client for Perforce Helix Core, for studios: artists first, experts in the same window. Windows 11 today; Ubuntu 24.04 is planned.

**Download, guides and release notes live here. The app's source code is private.**

- **Download the beta:** https://github.com/p4inz-code/ropework/releases (installer and portable zip, with checksums)
- **Website:** https://p4inz-code.github.io/ropework/
- **Guides:** [`guides/`](guides/) (tester guide, studio profile, test checklist, usability walk)
- **What changed:** [`CHANGELOG.md`](CHANGELOG.md)
- **Questions, bugs, ideas:** [open an issue](https://github.com/p4inz-code/ropework/issues/new/choose)

## What is in this repository
| Folder | What |
| --- | --- |
| `docs/` | the website as published (GitHub Pages) |
| `site/` | the website's source (`node build.mjs`, then `node check.mjs`) |
| `guides/` | guides for testers and studio admins |
| `releases/` | checksums and notes of each published version |

## Private by design
Ropework sends no telemetry. Your files and server details never leave your network; the app contacts the licence service only to confirm a licence. Read [Privacy and security](https://p4inz-code.github.io/ropework/privacy/).

Ropework is an independent product and is not affiliated with Perforce Software.
